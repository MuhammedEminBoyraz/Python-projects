# Döngüler - Çarpım Tablosu

## Açıklama
İç içe döngüler ve döngü kontrolü öğrenmek için yapılmış çarpım tablosu uygulaması.

## Özellikler
- Kullanıcıdan sayı alma
- 1'den 10'a kadar çarpım tablosu gösterme
- Tekrar sorma özelliği
- Geçersiz giriş kontrolü
- İç içe döngü kullanımı

## Öğrenilen Konular
- while döngüsü
- for döngüsü
- İç içe döngüler
- range() fonksiyonu
- break kullanımı
- exit() kullanımı

## Kullanım
```bash
python dongu.py
```
