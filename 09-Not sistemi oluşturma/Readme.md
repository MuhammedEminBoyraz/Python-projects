# Koşullu Durumlar - Not Harf Dönüştürücü

## Açıklama
if-elif-else yapısını öğrenmek için yapılmış not harf dönüştürücü.

## Özellikler
- 0-100 arası not alma
- 8 farklı harf notu (AA-FF)
- Geçersiz giriş kontrolü
- Tekrar sorma özelliği

## Öğrenilen Konular
- if-elif-else yapısı
- Çoklu koşul kontrolü
- and operatörü
- Aralık kontrolü

## Harf Notu Sistemi
- 90-100: AA
- 80-89: BA
- 70-79: BB
- 60-69: CB
- 50-59: CC
- 40-49: DC
- 30-39: DD
- 0-29: FF

## Kullanım
```bash
python kosul.py
```
