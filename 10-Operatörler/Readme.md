# Operatörler - Karşılaştırma ve Mantıksal

## Açıklama
Karşılaştırma ve mantıksal operatörleri öğrenmek için yapılmış uygulama.

## Özellikler
- 6 karşılaştırma operatörü (>, <, ==, !=, >=, <=)
- 3 mantıksal operatör (and, or, not)
- Tekrar sorma özelliği

## Öğrenilen Konular
- Karşılaştırma operatörleri
- Mantıksal operatörler (and, or, not)
- Boolean değerler
- Operatör kombinasyonları

## Kullanım
```bash
python operator.py
```
