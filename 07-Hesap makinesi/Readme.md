# Fonksiyonlar - Hesap Makinesi

## Açıklama
Fonksiyon tanımlama ve kullanımını öğrenmek için yapılmış hesap makinesi uygulaması.

## Özellikler
- 4 temel işlem (toplama, çıkarma, çarpma, bölme)
- Her işlem için ayrı fonksiyon
- Sıfıra bölme kontrolü
- Geçersiz giriş kontrolü
- Menu sistemi

## Öğrenilen Konular
- Fonksiyon tanımlama (def)
- return kullanımı
- Parametre gönderme
- Fonksiyon çağırma
- in operatörü ile kontrol

## Kullanım
```bash
python fonksiyon.py
```

## Örnek Çıktı
```
1.Toplama işlemi
2.Çıkarma işlemi
3.Çarpma işlemi
4.Bölme işlemi
0.Çıkış

Seçim: 1
```
