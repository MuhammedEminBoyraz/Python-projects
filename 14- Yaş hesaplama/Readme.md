# 📅 Yaş Hesaplama Programı

## 📌 Proje Açıklaması
Kullanıcının yaşını hesaplayan ve 100 yaşına dair bilgiler veren interaktif bir program.

## 🎯 Özellikler
- Mevcut yılı gösterme
- Yaş hesaplama
- 100 yaşına kalan süreyi hesaplama
- 100 yaşında olunacak yılı hesaplama
- Menü sistemi
- Tekrar kullanım seçeneği

## 🛠️ Kullanılan Teknolojiler
- Python 3
- `datetime` modülü

## 📖 Nasıl Çalıştırılır?
```bash
python yas_hesaplama.py
```

## 🎮 Kullanım
1. Menüden bir seçenek seçin (1-4)
2. Gerekirse doğum yılınızı girin
3. Sonuçları görün
4. Devam etmek için `e`, çıkmak için `h` tuşuna basın

## 💡 Öğrenilenler
- `datetime.date.today()` kullanımı
- `.year` özelliği ile yıl alma
- Menü tabanlı program yapısı
- String metodları (`.lower()`)
- Liste içinde kontrol (`in` operatörü)

## 📸 Örnek Çıktı
```
--- YAŞ HESAPLAMA ---
1. Hangi yılda olduğumuzu söyle
2. Kaç yaşında olduğumu söyle
3. 100 yaşına kaç yıl kaldığını söyle
4. Hangi yılda 100 yaşında olduğumu söyle

İşlem numarası: 2
Doğum yılınızı giriniz: 2000
Şu anda 26 yaşındasınız

Devam etmek istiyor musunuz? (e/h): 
```
