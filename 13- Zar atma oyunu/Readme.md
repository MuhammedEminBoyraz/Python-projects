# 🎲 Zar Atma Oyunu

## 📌 Proje Açıklaması
İki oyunculu basit bir zar oyunu. Her oyuncu 1-6 arası zar atar, yüksek atan kazanır!

## 🎯 Özellikler
- 2 oyuncu için rastgele zar atma
- Kazanan belirleme
- Beraberlik durumu
- Tekrar oynama seçeneği
- Geçersiz giriş kontrolü

## 🛠️ Kullanılan Teknolojiler
- Python 3
- `random` modülü

## 📖 Nasıl Çalıştırılır?
```bash
python zaratma.py
```

## 🎮 Kullanım
1. Program otomatik olarak her iki oyuncu için zar atar
2. Sonuçlar ekranda gösterilir
3. Kazanan belirlenir
4. Devam etmek için `E`, çıkmak için `H` tuşuna basın

## 💡 Öğrenilenler
- `random.randint()` kullanımı
- İç içe döngüler
- Input validasyonu
- String metodları (`.upper()`)

## 📸 Örnek Çıktı
```
Birinci oyuncu için zar atılıyor...
İkinci oyuncu için zar atılıyor...
Birinci oyuncunun attığı zar: 5, ikinci oyuncunun attığı zar: 3
Kazanan ==> BİRİNCİ OYUNCU
TEBRİKLER

Devam etmek istiyor musunuz?(E/H): 
```
